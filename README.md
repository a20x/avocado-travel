# Avocado Travel

Сайт продажи авиабилетов: поиск рейсов, выбор места на схеме салона, бронирование, личный кабинет, а также набор сервисов сайта (новости, форум, гостевая книга, статистика и другие).

Учебный проект по дисциплине «Web-программирование», ИАТЭ НИЯУ МИФИ. Один проект закрывает все лабораторные работы семестра. Авиакомпании, рейсы и продажи выдуманные, оплата демонстрационная.

Автор: Ермаков Александр, группа Биз-Б23.

## Быстрый старт

Нужны Node.js (LTS), pnpm и Docker Desktop.

```bash
pnpm install          # зависимости
cp .env.example .env  # переменные окружения
pnpm db:up            # PostgreSQL в Docker
pnpm db:migrate       # структура базы
pnpm db:seed          # демо-данные и администратор из .env
pnpm dev              # http://localhost:3000
```

Для тестов один раз скачайте браузер: `pnpm exec playwright install chromium`. Полная проверка проекта — `pnpm check`.

Вход администратора — `ADMIN_EMAIL` и `ADMIN_PASSWORD` из `.env` (по умолчанию `admin@avocado.local` / `avocado-admin`), админка — `/admin`.
