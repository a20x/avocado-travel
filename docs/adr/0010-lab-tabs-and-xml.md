# ADR-0010. Вкладки лабораторных и XML рядом с JSON

**Статус:** принято. Заменяет [ADR-0004](0004-json-instead-of-xml.md).

## Контекст

Преподаватель не нашёл лабораторные 2–4 в меню: страницы были, но лежали в «Ещё» под названиями «Пресс-центр», «Аналитика», «API и выгрузки». Методичка называет вторую лабу «XML и XSL», а четвёртую строит вокруг RSS и выгрузок в XML и ASCII — сбылся риск, записанный в ADR-0004. Одногруппники показывают работы отдельными вкладками «XML» и «БД» с поиском, сортировкой, паспортом базы и запросами к ней.

## Решение

- В основном меню — три вкладки: **XML** (`/xml`, лаба 2), **БД** (`/database`, лаба 3), **RSS** (`/rss`, лаба 4). «Авиакомпании» переезжают в «Ещё». Старые страницы остаются как были: «Пресс-центр» на JSON, «Аналитика», «API и выгрузки».
- **XML добавляется рядом с JSON, а не вместо него.** Те же 18 пресс-релизов лежат в `content/press/press-releases.xml` — файл собирается из JSON командой `pnpm press:xml`, совпадение проверяет тест. Рядом — схема `press-releases.xsd` и преобразование `press-releases.xsl` с параметрами поиска, выборки и сортировки. Вкладка «XML» читает именно XML-файл; XSL выполняется **на сервере** (`/xml/transform`) библиотекой `xslt-processor`: Chrome убирает встроенный XSLT, а сервер не зависит от браузера.
- **Вкладка «БД»** — новый модуль `database`: паспорт базы (объём, состав, полнота, актуальность) и пять видов запросов с формами, графиками и текстом выполненного SQL (`toSQL()` Drizzle, значения — параметрами $1, $2…). Своих таблиц у модуля нет.
- **Вкладка «RSS»** — модуль `exchange`: своя лента `/feed.xml` (RSS 2.0) рядом с `/feed.json`, внешние ленты в таблице `external_feeds` (администратор подключает и отключает их на сайте, вместо списка в коде), разбор загруженного RSS-файла и общая лента с выгрузкой в CSV, XML, RSS, текст ASCII через разделитель и ASCII в XML-тегах.

## Альтернативы

- **Заменить JSON на XML.** Пришлось бы переписывать «Пресс-центр» и терять JSON Schema; XML рядом даёт то же без потерь.
- **XSL в браузере** (инструкция `xml-stylesheet`). Оставлена как дополнительная возможность при открытии файла, но таблица и ссылка «Преобразование XSL» работают через сервер.
- **Список лент в коде, как раньше.** Проще, но подключить ленту без нового выпуска сайта нельзя, а у одногруппников это есть.

## Последствия

- Новая зависимость `xslt-processor` (LGPL-3.0, без своих зависимостей): XSLT 1.0 на чистом JavaScript. `fast-xml-parser` для разбора XML уже был.
- Новая таблица `external_feeds` — миграция `0013` переносит в неё три прежние ленты; на боевой базе она применяется сама при запуске.
- Подключение ленты по адресу — запрос сервера к чужому адресу. Защита от SSRF: только http(s), адреса внутренней сети отклоняются, каждая переадресация проверяется заново, подключать может только администратор.
- Вернуть меню как было — одна правка в `src/shared/config/navigation.ts`; убрать всё — `git revert` этого PR.
