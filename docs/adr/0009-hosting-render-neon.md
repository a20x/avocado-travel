# ADR-0009. Хостинг: Render, Neon и cron-job.org

**Статус:** принято. Заменяет [ADR-0006](0006-hosting-deferred.md).

## Контекст

Методичка требует бесплатный хостинг (L1-09). Сайту нужны Node.js, PostgreSQL и задания по расписанию. Сайт должен открываться из России у преподавателя и робота Яндекса, причём в любой момент: когда его откроют, заранее неизвестно, поэтому засыпающий сайт, который просыпается минуту, не подходит. Оплатить зарубежный сервис из России сложно, так что нужен тариф, бесплатный без срока.

Кандидаты проверялись в октябре 2026 года, доступность — с российских узлов check-host.net.

| Вариант | Что выяснилось |
|---|---|
| Render + Neon | Сайты `*.onrender.com` открываются из России. Бесплатный сайт засыпает через 15 минут, но 750 часов в месяц хватает на круглосуточную работу, если его будить. У Render бесплатная база удаляется через 30 дней, поэтому база — на Neon: 0,5 ГБ без срока |
| Vercel + Neon | Не засыпает, но по отзывам `*.vercel.app` нестабильно открывается на мобильном интернете в России; не использует наш `Dockerfile` |
| Koyeb | Для новых аккаунтов нужна банковская карта |
| Railway, Fly.io | Бесплатного тарифа без срока нет; railway.com с части российских узлов не открывается |
| Amvera, RelaxDev и другие российские | Доступны из России, но платные: бесплатен только стартовый бонус |
| Планировщик GitHub Actions | Запускает задания с опозданием на 10–30 минут и отключает расписание после 60 дней без коммитов |

## Решение

- Сайт — на Render из нашего `Dockerfile`, регион Франкфурт. Настройки сервиса — в `render.yaml`.
- База — PostgreSQL на Neon, тоже во Франкфурте.
- Задания по расписанию и запросы, которые не дают сайту заснуть, — cron-job.org.
- Миграции применяются при запуске сервера, деплой — автоматически после CI.

Порядок развёртывания и настройки — [09-deploy.md](../09-deploy.md).

## Последствия

- Бесплатно и без срока; привязать банковскую карту не нужно.
- 100 часов работы базы Neon в месяц: служебная страница, которую открывает планировщик, в базу не ходит, а автоотмена заказов на хостинге запускается раз в час вместо 5 минут.
- Перед Render стоит Cloudflare, и последний адрес в `X-Forwarded-For` — внутренний адрес Render. IP посетителя берётся из заголовка `True-Client-IP`, который Cloudflare перезаписывает (переменная `CLIENT_IP_HEADER`).
- 0,1 процессора: страницы рисуются медленнее, чем на ноутбуке. В Docker с такими же ограничениями страницы открывались за 0,4–1 с, изредка до 3 с; первая страница после деплоя — около 13 с.
- Код к Render не привязан: `Dockerfile` запускается на любом хостинге с Docker, все настройки — переменные окружения. Если Render перестанет открываться из России, переезд — новый сервис из того же образа.
