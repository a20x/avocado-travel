# ADR-0002. PostgreSQL и Drizzle ORM

**Статус:** принято

## Контекст

Лаба 3 требует приложение с базой данных, агрегатами и несколькими типами запросов. Нужен поиск по сайту с логическими операторами. Нужна защита от двойной продажи одного места.

## Решение

PostgreSQL как база, Drizzle ORM для работы с ней из TypeScript, drizzle-kit для миграций.

## Почему

- PostgreSQL — самая популярная реляционная база в индустрии. Встроенный полнотекстовый поиск с русской морфологией закрывает поиск по сайту без сторонних сервисов. Частичные уникальные индексы гарантируют, что место не продадут дважды.
- Drizzle пишет запросы почти как SQL, поэтому видно, что происходит в базе — полезно для понимания лабы 3. Типы результатов выводятся автоматически.

## Альтернативы

- **MySQL** (как в методичке) — слабее полнотекстовый поиск по-русски, нет частичных индексов.
- **Prisma** — популярна, но прячет SQL за своим языком запросов, а сложные агрегаты всё равно пишутся на сыром SQL.

## Последствия

- Локально база поднимается в Docker.
- На хостинге нужна управляемая PostgreSQL.
