# ADR-0006. Выбор хостинга откладывается до деплоя

**Статус:** принято

## Контекст

Нужен бесплатный хостинг с Node.js и PostgreSQL, доступный преподавателю и роботу Яндекса из России. На момент планирования популярные варианты либо частично недоступны в России (Vercel, Netlify), либо имеют ограничения бесплатного тарифа (засыпание приложения, удаление базы через срок).

## Решение

Разработка идёт локально (база в Docker). Хостинг выбирается на этапе 6 ([08-roadmap.md](../08-roadmap.md)) после проверки доступности кандидатов из России.

## Последствия

- Код не привязывается к особенностям конкретного хостинга: настройки только через переменные окружения, задания по расписанию — обычные API-маршруты с секретом.
- В проекте есть `Dockerfile`, чтобы приложение можно было развернуть где угодно.
