# ADR-0003. Процесс разработки: ветки, PR, Claude Code

**Статус:** принято

## Контекст

Проект — первый для автора, он учится по ходу разработки. Код пишет ИИ-ассистент, автор должен понимать каждую часть и уметь её объяснить.

## Решение

- Одна задача из [08-roadmap.md](../08-roadmap.md) — одна ветка и один PR.
- Код в репозитории пишет Claude Code по документации и [CLAUDE.md](../../CLAUDE.md), с подробным объяснением каждого решения.
- Ревью PR и архитектурные обсуждения — в отдельном чате с Claude, который открывает PR по ссылке.
- В `main` попадает только код, прошедший CI и ревью.

## Последствия

- Задачи небольшие, каждая объясняется отдельно — автор успевает разобраться.
- История изменений в git отражает логику развития проекта.
- Автор честно говорит о применении ИИ, если преподаватель спрашивает о процессе разработки.
