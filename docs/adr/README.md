# Записи архитектурных решений (ADR)

ADR — короткая запись о важном решении: в какой ситуации его принимали, что выбрали, какие были альтернативы и к чему это приводит. Через месяц никто не помнит, почему выбрали именно эту библиотеку, — ADR отвечает на этот вопрос.

Правила: файл `NNNN-краткое-название.md`, принятые решения не переписываются. Если решение меняется, пишется новый ADR со ссылкой на старый, а у старого статус меняется на «Заменено ADR-NNNN».
