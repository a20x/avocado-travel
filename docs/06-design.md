# 06. Дизайн

## Принципы

1. **Не как у агрегаторов.** Никакой горизонтальной строки полей поиска, никаких «синих кнопок найти», никаких фотографий со стоков.
2. **Спокойно и по-деловому.** Основа — графит и светлый туман, зелёный — акцент бренда, а не фон всего сайта.
3. **Собственная графика.** Иллюстрации и логотипы — свои SVG в плоском геометрическом стиле. Мотив бренда — авокадо: половинка с косточкой в логотипе, косточка как метка маршрута.
4. **Доступность.** Контраст текста не ниже WCAG AA (4,5:1), фокус клавиатуры всегда виден, все поля с подписями, сайт работает без мыши.

## Палитра

| Токен | Цвет | Назначение |
|---|---|---|
| `graphite` | `#2A2E33` | Основной текст, шапка, подвал |
| `slate` | `#4A5058` | Второстепенный текст, иконки |
| `mist` | `#EEF1EE` | Фон страниц |
| `sage` | `#BFD5A0` | Плашки, выделение, фон активных элементов |
| `avocado` | `#7FA54A` | Цвет бренда: логотип, иконки, плашки с графитовым текстом |
| `leaf` | `#3F6420` | Кнопки с белым текстом, ссылки |
| `pit` | `#8A5A3B` | Редкий акцент: метки маршрута, бейдж «выгодно» |
| `sky` | `#E8EDF0` | Небо в иллюстрациях, фон первого экрана главной |
| `line` / `line-strong` | `#D9DED8` / `#B9C0B8` | Разделители; рамки полей и свободных кресел |

Плюс служебные цвета: `white` для карточек, ошибки — `#A3261E` на `#F9E3E1`, предупреждения — `#7A5A00` на `#FBEFC5`.

**Где зелёный:** только там, где он что-то значит — основная кнопка, ссылки, логотип, выбранное состояние (кресло, вкладка, отмеченный фильтр). Фоны, плашки цен, рамки полей и вторичные кнопки — нейтральные (белый, `mist`, графит).

Важно: белый текст на `avocado` нечитаем (контраст ниже нормы), поэтому кнопки с белым текстом — только `leaf`.

Токены задаются один раз в конфигурации Tailwind и CSS-переменных. В компонентах — только токены, никаких «голых» HEX-кодов.

## Типографика

- Шрифт — **Onest**: современный, с хорошей кириллицей, бесплатный. Файлы шрифта лежат в репозитории (`src/app/fonts/`, лицензия OFL) и подключаются через `@font-face` в `src/app/globals.css` — три небольших файла (кириллица, латиница, латиница-расширенная с `₽`) вместо одного большого. От Google Fonts сайт не зависит.
- Шкала размеров: 14 / 16 (основной текст) / 18 / 22 / 28 / 36 / 48 px.
- Заголовки — полужирный, основной текст — обычный, межстрочный интервал текста 1,6.

## Поиск-фраза

Ключевой элемент главной. Поиск оформлен как предложение, где слова в рамках — поля:

> Я лечу из **[Москвы ▾]** в **[Калининград ▾]** **[14 ноября ▾]**, нас **[2 ▾]**, класс **[эконом ▾]**. **[Подобрать рейсы →]**

На узком экране предложение переносится по строкам и остаётся читаемым. Поля фразы шириной по выбранному значению. Дата — стандартный `<input type="date">`: браузер показывает её в формате системы (`14.11.2026`), а словами («14 ноября») она написана на странице результатов.

Списки фразы (города, пассажиры, класс) с мышью — свои: стандартный `<select>` раскрывает меню шрифтом самого поля, а во фразе он крупный, и меню городов занимало весь экран. Свой список — обычным шрифтом, не выше 18 rem с прокруткой, выбранный пункт выделен; с клавиатуры — стрелки, Home/End, Enter, Escape и переход по первым буквам (образец WAI-ARIA «combobox со списком»). На сенсорном экране и без JavaScript — стандартный `<select>`: на телефоне система показывает удобное окно выбора.

## Компоненты

Общие компоненты лежат в `src/shared/ui/`. Каждая страница собирается из них; новые варианты кнопок или карточек добавляются в общий набор, а не рисуются заново на месте. Все компоненты на одной странице — `/dev/ui` (только в режиме разработки).

- **Готовы:** Button, Input, Select, Card, Badge, Tabs, EmptyState, Table (T-05); DatePicker, Skeleton (T-10); Toast (T-13); Dialog (T-14); Pagination, Textarea (T-16); ActionForm и ConfirmButton — форма-кнопка для Server Action и кнопка с подтверждением (T-17).

Где возможно, компоненты построены на стандартных элементах HTML (`<select>`, `<dialog>`, `<input type="date">`): управление с клавиатуры браузер даёт сам, сторонние библиотеки не нужны.

## Адаптивность

Сайт проектируется от мобильного экрана: 360 px → 768 px → 1280 px. Таблицы на узких экранах прокручиваются по горизонтали внутри своего блока, страница целиком вбок не прокручивается.

## Процесс

До начала вёрстки делается **дизайн-концепция**: палитра на реальных экранах, типографика, логотип и макеты главной, результатов поиска, страницы рейса со схемой салона и личного кабинета. Концепция утверждается автором проекта, после этого по ней пишется код. Изменения дизайна после утверждения — сначала в концепции, потом в коде.

Концепция **утверждена 21.10.2026** и лежит в [`docs/design/`](design/index.html): откройте `index.html` в браузере — там палитра, шрифт и макеты главной, результатов поиска, страницы рейса и личного кабинета на 1280 и 360 px. Макеты — статический HTML, а не код сайта: в T-05 из них переносятся токены и компоненты. Изображения сайта — в `public/images/` (описание — `public/images/README.md`).

Решения концепции:

- **Шапка:** Рейсы · Направления · Авиакомпании · Новости · Сервисы · Ещё ▾ (погода, форум, гостевая книга, пресс-центр, аналитика, API, полезные ссылки, справка); справа поиск по сайту и вход. На телефоне — кнопки поиска и меню. «Ещё» открывается при наведении мыши и закрывается, когда мышь ушла (с задержкой 0,2 с, чтобы путь до списка его не закрывал), по Escape, щелчку мимо и после выбора пункта; с клавиатуры и на сенсорном экране — нажатием. Меню телефона так же закрывается после выбора страницы и поиска, по Escape и щелчку мимо. Полоса вкладок, которая не помещается на узком экране, прокручена к текущей вкладке.
- **Главная сверху вниз:** поиск-фраза на иллюстрации → популярные направления → промо-блоки → погода, опрос, рейтинг → содержание сайта. Счётчик посещений и курсы валют — в подвале.
- **Справка:** оглавление слева в карточке, прилипает при прокрутке (на телефоне — над текстом); разделы — карточки с вопросами. Вопрос, к которому перешли по якорю, подсвечен фоном `sage-light`.
- **Рейс в списке:** маршрут — пунктир с косточкой `pit` на конце; цена и кнопка — в отдельной светлой колонке.
- **Схема салона:** кресла-кнопки с номером; занятые — серые без номера, выбранные — `leaf`, с дополнительным местом для ног — рамка `pit`. На телефоне итог и кнопка — в нижней панели, схема остаётся видна.
- **Тёмной темы нет.**
