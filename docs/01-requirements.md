# 01. Требования

Источник: «Лабораторный практикум по курсу Web-технологии» (методичка преподавателя, лежит в `docs/source/`). Методичка написана в 2009 году под PHP, MySQL и Apache. Преподаватель разрешил Node.js, поэтому все требования выполняются на стеке из [03-architecture.md](03-architecture.md), а не на PHP.

Тема проекта — вариант №2 из приложения 1: **«Заказ билетов (вид транспорта – билет – заказчик – номер рейса)»**. Сайт только про авиаперелёты, поэтому «вид транспорта» реализован как **модель воздушного судна** (Airbus A320neo, Boeing 737-800 и т.д.) — см. [04-data-model.md](04-data-model.md).

Каждое требование ниже имеет код (например, `L1-07`). Коды используются в задачах, PR и при сдаче, чтобы было видно, что чем закрыто.

## Лаба 2. Представление структурированных данных

Срок по методичке: второй месяц.

В методичке лаба называется «XML и XSL». По решению автора проекта она реализуется на **JSON** — [ADR-0004](adr/0004-json-instead-of-xml.md). Если преподаватель потребует именно XML, добавляется XML-представление тех же данных, архитектура это предусматривает.

| Код | Требование методички | Чем закрываем |
|---|---|---|
| L2-01 | Структурировать новости тегами: 15–20 записей, 5–7 тегов | Файл `content/press/press-releases.json`: 18 пресс-релизов, у каждого 7 полей (`id`, `title`, `date`, `category`, `author`, `summary`, `body`) |
| L2-02 | Описать структуру данных | JSON Schema `content/press/press-releases.schema.json` + Zod-схема, данные проверяются при загрузке |
| L2-03 | Преобразование данных в HTML (аналог XSL) | Серверная функция-преобразователь «данные → модель отображения» + React-компоненты |
| L2-04 | Сортировка и выборка | Сортировка по дате, заголовку, категории; фильтр по категории и автору; параметры в адресе страницы |
| L2-05 | Приложение для представления данных, включённое в сайт | Страница `/press` в общем меню |
| L2-06 | Демонстрация | На странице `/press` — ссылки на исходный JSON и на схему |

## Лаба 3. Web-приложение с базой данных

Срок по методичке: третий месяц.

| Код | Требование методички | Чем закрываем |
|---|---|---|
| L3-01 | Приложение, работающее с базой данных | Весь сайт на PostgreSQL; для отчёта — раздел «Аналитика продаж» |
| L3-02 | 3–5 типов запросов | Пять отчётов, см. ниже |
| L3-03 | Графики и диаграммы | Линейный график, столбчатые и круговая диаграммы |
| L3-04 | Агрегированные данные | `COUNT`, `SUM`, `AVG`, `MAX`, группировки по периоду, авиакомпании, направлению |

Отчёты страницы `/analytics`:

1. **Выручка по месяцам** за выбранный период — линейный график.
2. **Топ-10 направлений** по числу проданных билетов — столбчатая диаграмма.
3. **Заполняемость рейсов** по авиакомпаниям и моделям самолётов — доля мест улетевших рейсов, проданных через Avocado Travel (демо-данные продают лишь малую часть мест, см. [04-data-model.md](04-data-model.md#демо-данные)), — столбчатая диаграмма.
4. **Структура продаж**: доля классов «эконом» и «бизнес», доля отмен — круговые диаграммы.
5. **Отчёт с фильтрами**: период, авиакомпания, направление → таблица с итогами (количество, сумма, средний чек, максимальный чек).

Плюс статистика рекламы (показы, клики, CTR) из сервиса L1-S12.

## Лаба 4. Обмен данными между приложениями

Срок по методичке: четвёртый месяц.

| Код | Требование методички | Чем закрываем |
|---|---|---|
| L4-01 | Обмен данными между приложениями | Публичный REST API `/api/v1` в формате JSON с документацией OpenAPI на странице `/api/docs` |
| L4-02 | Лента новостей для подписки (в методичке RSS) | JSON Feed 1.1 по адресу `/feed.json`, генерируется из базы новостей |
| L4-03 | Выгрузка в табличный формат (CSV) | Выгрузка рейсов, новостей и отчётов аналитики в CSV |
| L4-04 | Выгрузка в XML и «ASCII в XML-тегах» | Покрывается JSON-форматом API по ADR-0004. XML-выгрузка добавляется, если потребует преподаватель |
| L4-05 | Получение данных из внешних источников | Импорт новостей авиаотрасли из внешних RSS-лент по расписанию |
| L4-06 | Загрузка в другую СУБД или прикладная обработка | Обработка импортированных новостей: удаление дублей, автоматические теги, показ в разделе «Новости отрасли» |

Подробности — [05-api.md](05-api.md).

## Требования к оформлению отчётов

Отчёт по каждой лабе оформляется по шаблонам из приложений методички. Отчёты не входят в репозиторий кода и готовятся отдельно.
