# Изображения Avocado Travel

Все изображения нарисованы специально для проекта в формате SVG (векторная графика: чёткая на любом экране, весит мало, правится в любом текстовом редакторе). Чужих изображений и стоковых фото нет.

Папка лежит в `public/images/`, поэтому файлы доступны на сайте по адресам вида `/images/brand/logo.svg`.

## brand/ — фирменный стиль

| Файл | Где использовать |
|---|---|
| `logo.svg` | Логотип в шапке на светлом фоне |
| `logo-light.svg` | Логотип на тёмном фоне (подвал) |
| `logo-mark.svg` | Только знак, без надписи: мобильная шапка, загрузка |
| `favicon.svg` | Иконка вкладки браузера, упрощённый знак |
| `og-image.png` | Превью ссылки в мессенджерах и соцсетях (`<meta property="og:image">`). PNG, потому что SVG соцсети не показывают |
| `og-image.svg` | Исходник превью для правок |
| `apple-touch-icon.png` | Иконка сайта на экране «Домой» в iPhone и iPad (`<link rel="apple-touch-icon">`). 180×180, PNG без прозрачности: iOS не понимает SVG, а прозрачный фон заливает чёрным |
| `apple-touch-icon.svg` | Исходник иконки для правок |

Знак — половинка авокадо, перевёрнутая острым концом вниз: она же метка на карте, косточка на месте отверстия метки.

## airlines/ — логотипы авиакомпаний

Шесть выдуманных авиакомпаний, у каждой свой цвет и эмблема:

| Файл | Название | Код | Цвет | Эмблема |
|---|---|---|---|---|
| `lastavia.svg` | Ластавиа | LST | `#2E4A7D` | Ласточка |
| `ornavia.svg` | Орнавиа | ORN | `#9A4A2E` | Крыло из перьев |
| `aerella.svg` | Аэрелла | ARL | `#5B4B8A` | Хвостовое оперение |
| `striva.svg` | Стрива | STV | `#1F6F6A` | Шевроны (стриж) |
| `kirra.svg` | Кирра | KRR | `#3B78A0` | Перистые облака |

Эти названия, коды и цвета используются в демо-данных (задача T-07).

`default.svg` — общий логотип (серый квадрат с самолётом) для авиакомпаний, которые администратор заводит в админке: загрузить свой рисунок там нельзя.

## illustrations/ — иллюстрации

|---|---|

## ads/ — рекламные баннеры

Картинки для рекламных кампаний (поле `image` в `ad_campaigns`, задача T-24). Размер 600×300 (2:1). Текста на картинках нет: заголовок и текст кампании выводятся HTML-разметкой рядом, чтобы их читали поисковики и экранные дикторы.

| Файл | Тема кампании |
|---|---|
| `early-booking.svg` | Скидка за раннее бронирование |
| `baggage.svg` | Багаж включён в тариф |
| `sea-weekend.svg` | Выходные у моря |
| `winter-mountains.svg` | Зимний отдых в горах (подходит для кампании с истёкшим сроком) |

## Палитра

Все изображения используют только цвета из `docs/06-design.md`: графит `#2A2E33`, сланец `#4A5058`, шалфей `#BFD5A0`, авокадо `#7FA54A`, тёмный лист `#3F6420`, косточка `#8A5A3B` и производные оттенки. В иллюстрациях направлений и баннерах для воды используется приглушённый сланец `#7D8790`, для песка и фасадов — светлая косточка `#E3D3BF`, для шпилей — золото Альтэйры `#A87B22`, для неба — нейтральный `sky` `#E8EDF0`.
